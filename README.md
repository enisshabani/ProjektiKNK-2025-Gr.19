# ProjektiKNK - 2025 - Gr.19
Zhvillimi i Sistemit Interaktiv per aplikimin dhe menaxhimin  e dhomave me studentë në konvikte

**Përmbledhje e Projektit**

Ky projekt, është një sistem gjithëpërfshirës i projektuar për të menaxhuar dhe thjeshtuar procesin e menaxhimit të studentëve në konvikte. Sistemi është ndërtuar duke përdorur Java dhe JavaFX, dhe përfshin disa kontrollues dhe FXML files për të trajtuar ndërfaqen e përdoruesit.

Si të ekzekutoni projektin

* Clone repositorin nga GitHub duke përdorur komandën: git clone https://github.com/enisshabani/ProjektiKNK-2025-Gr.19.git
* Hapeni projektin në IntelliJ IDEA.
* Sigurohuni që të gjitha bibliotekat e nevojshme janë përfshirë në projekt.
* Konfiguroni cilësimet e lidhjes me bazën e të dhënave në skedarin DatabaseUtil.java.
* Ekzekutoni aplikacionin duke nisur klasën Main.

Tools të nevojshëm:

* Java Development Kit (JDK) 8 ose më i lartë
* JavaFX SDK
* Një IDE si IntelliJ
* Scene Builder
